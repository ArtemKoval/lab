# Technical Glossary

- ASD-STE100: Simplified Technical English, the writing style of this repo.
- ASIT: Advanced Systematic Inventive Thinking. Solve inside the closed world before you add components.
- ADR: architecture decision record; a durable decision file under adr/, immutable once accepted.
- Council notes: the audit trail beside an artifact that records author, reviewer challenges, and resolutions.
- Spec delta: the ADDED, MODIFIED, or REMOVED requirement block a change holds for one capability.
- Supersession: the only way an accepted ADR changes; a new ADR names the old one in Supersedes.
- Harness: the agent setup of this repo: pipeline skill, skills, agents, hooks, permissions, and gates.
