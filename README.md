## Installing OpenSpec
- https://github.com/Fission-AI/OpenSpec/blob/main/docs-lab/start/installation.md#install-with-your-ai-assistant

To install OpenSpec with the command line, run `npm install -g @fission-ai/openspec@latest`. This command needs Node.js 20.19.0 or newer.

## Set up a clean clone
The file `tools/project_setup/registry.json` lists the tools that a clean clone needs. In Claude Code, use the `project-setup` skill to check them and install the missing ones.
